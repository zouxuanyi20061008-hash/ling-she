# 🐍 灵蛇问道 · 青岚仙境

一款使用 HTML5 Canvas 制作的国风仙侠灵蛇进化游戏，面向安卓横屏浏览器。当前仓库为持续开发中的 **V6.5 妖兽美术与战斗反馈测试版**，并非最终美术验收版。

## 直接游玩

- 在线版：https://zouxuanyi20061008-hash.github.io/ling-she/
- 离线版下载页：https://zouxuanyi20061008-hash.github.io/ling-she/download.html
- 单文件游戏：[`offline.html`](./offline.html)，已内嵌美术和游戏脚本，包括 V6.0 试炼碑、V6.2 妖兽和 V6.4 五境灵蛇与 V6.5 八种妖兽及幽冥妖王美术和战斗反馈，可下载发送给好友；部分安卓浏览器会限制本地 HTML 的持久存档功能。

## 玩法

- **移动**：触摸左下角虚拟摇杆；电脑可用 WASD / 方向键。
- **技能**：灵蛇遁、回春术、灵息弹、突破；电脑快捷键分别是空格、E、F、B。
- **智能任务引导（V6.1）**：默认只显示一张短任务卡；探索时突出当前目标、方向和约略路线距离，战斗时自动收起。小地图显示可通行路径，目标不在屏幕内时用方向箭头指向路线下一段；路径规避河流和建筑碰撞。
- **引导模式**：打开游历簿，点击「任务引导：智能 ↻」可切换智能、极简、详细三种模式。选择会随当前存档保存，旧存档默认智能。
- **道途游历簿**：点击屏幕上的「📜」按钮，电脑可按 P；查看七卷修仙主线、自动刷新的巡山悬赏、道纹成长及试炼位置。任务完成后自动结算奖励。
- **三境试炼**：在寒霜雪境找到寒镜遗迹（3阶解封，限时集寒魄）、赤炎荒漠找到赤炎古柱（5阶解封，躲避火环并取炎晶）、幽冥魔域找到幽冥封印（7阶解封，击败封印守卫）。接近试炼碑，点击互动按钮或按 G。首次通关有额外奖励，重访有冷却时间。
- **道纹成长**：完成主线与悬赏可以积累道纹，提高基础攻击与移动速度，存档长期保留。
- **机缘**：寻找碧泉灵汐、千年灵木、青岚祠。接近机缘点后，点击屏幕上的「感悟」按钮；电脑可按 G。首次感悟可得修为与资源，机缘祝福提供短时增益，重访有冷却时间。
- **青岚区域首领**：苍牙狼王。靠近后触发扑击与妖气攻击；血量降低后进入狂怒阶段。
- **化形**：凡蛇 → 灵蛇 → 妖蟒 → 蛟龙 → 真龙，蛇头、蛇身、光效和技能表现随境界升级。
- **妖兽生态**：青岚原生灵兔逃跑、狐妖游斗、山狼冲锋、岩龟减伤、妖蝠远攻。
- **三境区域专属妖兽（V6.2）**：寒霜雪境的霜角灵鹿会保持距离并施加减速；赤炎荒漠的赤砂炎蝎会扑击和扇形喷火；幽冥魔域的幽冥鬼灯可闪现和施加削弱攻击的幽咒。妖兽拥有独立 SVG 美术与不同 AI。
- **灵材与永久功法**：击败这些妖兽分别获得寒魄、炎晶、幽魄；各收集 4 份时自动解锁冰鳞护体（缓解减速并小幅减伤）、炎脉灼击（灵息弹对妖兽附加持续伤害）、幽息回元（击杀回血并减轻幽咒）。在游历簿下方查看收集进度，无须新增常驻 HUD。

## V6.3a 青岚平原美术重制

- **草地**：调整青岚地表调色板，增加确定性的低对比草簇、地面色块和小花，避免重复平铺的强烈色块感。
- **古道**：重绘石路纹理，增加自然路缘与细碎石子；青岚山门道路和祠堂仍沿用原来可通行地形。
- **水岸**：河水分层为湿土、沙岸、深水、浅青水面；岸边岩石、草丛和波纹都在地形分块中缓存。移除了逐帧绘制河岸贴图。
- **植被**：统一 `ancient-tree.svg` 与 `jade-bamboo.svg` 的明暗、轮廓和阴影，仍有原有前景树冠遮挡。
- **技术边界**：更新仅在渲染/素材层进行。河流、木桥、悬崖与场景障碍碰撞未改变；对安卓实际性能的影响尚待真机验收。

## V6.3b 林间空间层次与桥崖美术

- **木桥**：`stone-bridge.svg` 重绘桥板木纹、栏杆、桥墩、光影；在桥上的特定前后关系下，南侧栏杆才覆盖灵蛇。仍使用既有桥面坐标和通行判定。
- **悬崖**：`mossy-cliff.svg` 改为整块青灰石壁，修正旧版四块重复贴图的视觉接缝，加入岩层、苔藓、裂纹和基部投影。角色走到岩壁前缘时有轻量局部遮挡。
- **林间灌木**：新增 `qinglan-fern.svg` 蕨类灌木，通过 `terrain-cache.js` 静态缓存投放，符合道路和机缘点周围的留白规则。
- **前后景**：树冠遮挡透明度下调；竹叶和蕨叶仅在角色真的走到后方时，使用局部地图格子查找进行小幅叠绘，不扫描全地图。
- **本轮边界**：没有改变人物、妖兽、桥梁或悬崖的碰撞数据，没有改变存档结构。性能与色彩效果仍需在真实安卓设备上验收。

## V6.3c 青岚晨光、薄雾与贴地表现

- **晨光地面**：新增 `assets/qinglan-atmosphere.js`，以三张启动时生成并复用的小纹理画布表现林下柔和光斑、透光光束、溪畔雾气；只在可见范围内使用，固定世界坐标不干扰路径辨认。
- **河面反光**：对屏幕内河道绘制低密度微波光；桥梁位置跳过高光，避免遮盖可通行桥面。
- **灵蛇贴地**：在绘制灵蛇精灵之前绘制头部和尾部的扁椭圆投影，随进化大小调整，保留原有五境造型和技能。
- **细微动效**：高清模式增加少量光束、雾与灵光，流畅模式降低显示数量与透明度；没有加入大范围实时滤镜。
- **兼容**：不修改任何地形碰撞、任务、AI 或存档字段；V4 存档结构与键名不变，旧存档兼容。实际安卓手机上的视觉与帧率仍需验收。

## V6.4 五境化形美术重制

- **十张角色 SVG**：完整重绘 `jade-snake-head/body.svg` 以及 `evo1` 至 `evo4` 各境界头、身体素材，不再仅依赖换色区分境界。每套有独立轮廓、纹理和边缘细节。
- **辨识度**：凡蛇为青绿素鳞；灵蛇带玉鳍和额前玉纹；妖蟒有宽额颊甲、尖牙和重鳞；蛟龙有双角、龙须和青蓝水纹；真龙有分叉龙角、鬃饰、金鳞和更亮的龙纹。
- **角色比例**：游戏内五境蛇头绘制大小依次为 40／50／61／70／80；对应身体鳞片大小为 23／30／36／40／47（单位：世界绘制像素，随蛇尾收窄）。
- **突破表现**：增加中后期境界的短暂放射灵光与稀疏鳞片高光；高级画质比流畅画质显示更多微光。化形判定和战斗数值不变。
- **加载兼容**：全部十张素材使用 `?v=64` 防止浏览器沿用旧图；独立离线 HTML 完整嵌入所有新贴图。素材不可用时有原有 Canvas 备用显示。
- **不改玩法**：仍使用 `lingshe_v4_save`；五境技能、突破阈值、妖兽 AI、地形碰撞和主线保持原状。真实手机上的美术与帧率仍需进一步验收。

## V6.5 妖兽美术与战斗反馈重制

- **八种妖兽**：青岚平原的灵兔、狐妖、山狼、岩龟、妖蝠，以及寒霜、赤炎、幽冥三境的灵鹿、炎蝎、鬼灯，均细化了专属 SVG 的纹理和轮廓。
- **幽冥妖王**：新增 `assets/nether-overlord.svg` 独立原创妖王像，替代原先的纯圆形临时绘制；贴图失败时保留旧版回退表现。
- **战斗反馈**：新增 `assets/combat-art.js`，提供命中与击败的短暂冲击纹理环、敌人贴地阴影、精英灵气轮廓和利用现有远程攻击冷却的简洁提示。
- **区域法弹**：霜寒改为锋利冰晶、炎弹改为火焰拖尾、幽咒改为紫色符文球；不改变实际弹道、命中盒、异常状态和伤害。
- **运动**：按物种增加低幅度轻摆、呼吸与受击闪光，保证外观与原有碰撞范围大体一致。
- **性能**：短时命中效果最多 30 个，屏外不加入新效果，过期自动移除；流畅画质降低轮廓和粒子数量。
- **功能稳定**：八种妖兽原有 AI、技能 CD、主线与试炼、游戏碰撞、经验奖励和 `lingshe_v4_save` 存档结构均未更改；真实手机帧率仍须实测。

## 兼容性和性能

- 采用分块地图纹理缓存、低开销光效和手机默认流畅画质；可切换画质并查看 FPS。
- 三境试炼碑拥有独立 SVG 美术，地图上有区域标记；试炼在屏幕外不产生复杂的绘制开销。
- 存档键保持为 `lingshe_v4_save`，数据 `version: 4`，V6.5 继续保持 V4 存档键和结构；此前机缘、主线、悬赏、试炼、引导偏好与灵材收集仍是**可选字段**，旧存档没有新字段也可以读取。
- 在线版和离线 HTML 属于不同浏览器来源，进度**不会自动同步**。
- 仍需真实安卓设备上进行长时间帧率、兼容性和关卡平衡验收。

## 项目文件

- `index.html`：在线游戏、UI、战斗循环和保存加载。
- `assets/art-layer.js`、`assets/terrain-cache.js`：世界场景、桥栏和植被层次、静态缓存。
- `assets/evolution.js`：V6.4 五境化形比例、鳞片微光和突破特效。
- `assets/jade-snake-*.svg`、`assets/evo*-head/body.svg`：十张五境原创头部与鳞片贴图。
- `assets/creatures.js`：妖兽种类、AI 与 V6.5 的物种独立细微动作。
- `assets/combat-art.js`：妖兽命中冲击、击败反馈、精英地面气场、远程预警与幽冥妖王绘制。
- `assets/nether-overlord.svg`：幽冥妖王独立原画资源。
- `assets/encounters.js`：机缘、探索任务、苍牙狼王。
- `assets/adventure.js`：七卷主线、循环悬赏、道纹成长和三境试炼。
- `assets/guidance.js`：任务优先级、战斗动态收起、可通行路径寻路及目标高亮。
- `assets/biome-ecology.js`：三境妖兽战斗习性、冰火幽异常状态、灵材掉落和永久功法。
- `assets/qinglan-surface.js`：V6.3a 的静态草地、石路、河道与岸边细节绘制。
- `assets/qinglan-atmosphere.js`：V6.3c 的晨光、河面微光、薄雾以及灵蛇贴地投影。
- `assets/terrain-cache.js`：400px 分块缓存，等待美术资源加载后自动使相关缓存失效。
- `assets/*.svg`：原创角色和场景美术资源。
- `offline.html`：不依赖额外素材文件的单页离线构建。

当前为单人本地游戏；存档存在玩家各自的浏览器中。
