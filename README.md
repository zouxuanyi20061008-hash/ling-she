# 🐍 灵蛇问道 · 青岚仙境

一款使用 HTML5 Canvas 制作的国风仙侠灵蛇进化游戏，面向安卓横屏浏览器。当前仓库为持续开发中的 **V6.2 三境妖兽生态测试版**，并非最终美术验收版。

## 直接游玩

- 在线版：https://zouxuanyi20061008-hash.github.io/ling-she/
- 离线版下载页：https://zouxuanyi20061008-hash.github.io/ling-she/download.html
- 单文件游戏：[`offline.html`](./offline.html)，已内嵌美术和游戏脚本，包括 V6.0 的试炼碑和 V6.2 的三种妖兽原创美术，可下载发送给好友；部分安卓浏览器会限制本地 HTML 的持久存档功能。

## 玩法

- **移动**：触摸左下角虚拟摇杆；电脑可用 WASD / 方向键。
- **技能**：灵蛇遁、回春术、灵息弹、突破；电脑快捷键分别是空格、E、F、B。
- **智能任务引导（V6.1）**：默认只显示一张短任务卡；探索时突出当前目标、方向和约略路线距离，战斗时自动收起。小地图显示可通行路径，目标不在屏幕内时用方向箭头指向路线下一段；路径规避河流和建筑碰撞。
- **引导模式**：打开游历簿，点击「任务引导：智能 ↻」可切换智能、极简、详细三种模式。选择会随当前存档保存，旧存档默认智能。
- **道途游历簿**：点击屏幕上的「📜」按钮，电脑可按 P；查看七卷修仙主线、自动刷新的巡山悬赏、道纹成长及试炼位置。任务完成后自动结算奖励。
- **三境试炼**：在寒霜雪境找到寒镜遗迹（3阶解封，限时集寒魄）、赤炎荒漠找到赤炎古柱（5阶解封，躲避火环并取炎晶）、幽冥魔域找到幽冥封印（7阶解封，击败封印守卫）。接近试炼碑，点击互动按钮或按 G。首次通关有额外奖励，重访有冷却时间。
- **道纹成长**：完成主线与悬赏可以积累道纹，提高基础攻击与移动速度，存档长期保留。
- **机缘**：寻找碧泉灵汐、千年灵木、青岚祠。接近机缘点后，点击屏幕上的「感悟」按钮；电脑可按 G。首次感悟可得修为与资源，机缘祝福提供短时增益，重访有冷却时间。
- **青岚区域首领**：苍牙狼王。靠近后触发扑击与妖气攻击；血量降低后进入狂怒阶段。
- **化形**：凡蛇 → 灵蛇 → 妖蟒 → 蛟龙 → 真龙，蛇头、蛇身、光效和技能表现随境界升级。
- **妖兽生态**：青岚原生灵兔逃跑、狐妖游斗、山狼冲锋、岩龟减伤、妖蝠远攻。
- **三境区域专属妖兽（V6.2）**：寒霜雪境的霜角灵鹿会保持距离并施加减速；赤炎荒漠的赤砂炎蝎会扑击和扇形喷火；幽冥魔域的幽冥鬼灯可闪现和施加削弱攻击的幽咒。妖兽拥有独立 SVG 美术与不同 AI。
- **灵材与永久功法**：击败这些妖兽分别获得寒魄、炎晶、幽魄；各收集 4 份时自动解锁冰鳞护体（缓解减速并小幅减伤）、炎脉灼击（灵息弹对妖兽附加持续伤害）、幽息回元（击杀回血并减轻幽咒）。在游历簿下方查看收集进度，无须新增常驻 HUD。

## 兼容性和性能

- 采用分块地图纹理缓存、低开销光效和手机默认流畅画质；可切换画质并查看 FPS。
- 三境试炼碑拥有独立 SVG 美术，地图上有区域标记；试炼在屏幕外不产生复杂的绘制开销。
- 存档键保持为 `lingshe_v4_save`，数据 `version: 4`，V6.2 的机缘、主线、悬赏、试炼、引导偏好与灵材收集作为**可选字段**加入，旧存档没有新字段也可以读取。
- 在线版和离线 HTML 属于不同浏览器来源，进度**不会自动同步**。
- 仍需真实安卓设备上进行长时间帧率、兼容性和关卡平衡验收。

## 项目文件

- `index.html`：在线游戏、UI、战斗循环和保存加载。
- `assets/art-layer.js`、`assets/terrain-cache.js`：世界场景和缓存。
- `assets/evolution.js`：灵蛇化形、技能视觉演出。
- `assets/creatures.js`：妖兽种类、AI 和绘制。
- `assets/encounters.js`：机缘、探索任务、苍牙狼王。
- `assets/adventure.js`：七卷主线、循环悬赏、道纹成长和三境试炼。
- `assets/guidance.js`：任务优先级、战斗动态收起、可通行路径寻路及目标高亮。
- `assets/biome-ecology.js`：三境妖兽战斗习性、冰火幽异常状态、灵材掉落和永久功法。
- `assets/*.svg`：原创角色和场景美术资源。
- `offline.html`：不依赖额外素材文件的单页离线构建。

当前为单人本地游戏；存档存在玩家各自的浏览器中。
