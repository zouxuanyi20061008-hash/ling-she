# 太乙 V67 · 岁计定计目与中五大参将

## 原典验收

《[太乙指津·求定计目法](https://ctext.org/wiki.pl?chapter=948786&if=gb)》和《[古今图书集成·主客定计](https://higrid.net/show/ancient/80-36.html)》：岁计用**太岁年支六合支**加于太岁年支所在的十六神地盘，旋盘后找到**天盘文昌所临的地盘神**作为定计目。由定计目依 V65 正宫记宫数、间神起算一，数到太乙宫**前止**，得定算及大将、参将；起算目若恰在太乙宫，沿用 V66 明示的同宫默认或保守口径，不混淆。

数学：十六神按子、丑、艮、寅、卯、辰、巽、巳、午、未、坤、申、酉、戌、乾、亥排列。若六合神位在天盘索引 h、太岁地支在地盘索引 b、文昌天盘索引 w，定计地盘索引 `(w-h+b) % 16`；保存16个宫位的天地互映，便于独立核验。

- 《古今图书集成》**汉献帝建安五年庚辰**（仅作为古籍例盘，历史年不直接送 1901–2099 API）：太乙七宫、文昌大武（坤），酉合加辰，文昌下临**寅吕申**，顺行 **寅1 + 卯4 + 巽9 + 午2 = 定算16**，定计大将6、参将8。
- 《太乙指津》**辛未**例：太乙三宫、文昌大神巳，午合加未，文昌下临**午大威**，顺行 **午2 + 坤7 + 酉6 + 乾1 + 子8 = 定算24**，定计大将4、参将2。
- 本站 2026 丙午年：文昌武德申、太乙三宫，未合加午，定计目坤，定算 **22**（坤7+酉6+乾1+子8），定计大将2、参将6。不能将此年份硬编码成示例结果；使用通用十六神转盘算法。

## 中五

《[太乙秘书](https://zh.wikisource.org/zh-hans/太乙秘書)》有大将、参将“**不出中宫**”条。**太乙不入中五**与**大参将计算值可以为5**是不同概念。第56局（2027），主算15，主大将5、参将5；第57局（2028），客算25，大将5、参将5。网站保留五宫，标记 `is_middle_five=true`、`status=中五不出`，绝不偷转为0宫、未定义或任意八宫，且原来太乙中五不入仍保持。

## 工程与边界

后端 `backend/app/core/taiyi_v67.py` 添加定计源头六六合映射、十六神天地转盘及可逐项核验累算；`year_board()` 默认 V67。整盘九宫同步标注定计目（在正宫时）、定计大将、定计参将和中五将。
