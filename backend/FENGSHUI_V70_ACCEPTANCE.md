# V70 堪舆风水 · 二十四山坐向与九宫实算独立验收

## V70 范围

- 用户输入正北顺时针角度（0°～360°），明确这是朝向还是坐向；按半周差 180° 推算对应方向。
- 真北输入直接按真北方位角；磁北输入**必须**同时提供用户自行核实的磁偏角（东偏为正、西偏为负），服务端据此换算；拒绝猜测城市磁偏角，拒绝真北读数重复校正。
- 二十四山每山 15°、中心与起止角、对宫、后天八卦归属与九宫数。
- 15°山界采用左闭右开机械约定，距离任一山界 ≤0.2° 输出复测警示；精确山界不会被宣称为确定立向。
- 九宫以传统上南下北、左东右西展示，中宫五不映射二十四山。
- 不识别实地轴线/设备传感器，不做玄空飞星、形势吉凶或分金择向判断。

## 独立区间资料

- <https://www.yuanka.com.cn/tools/luopan>：24山起止角度、坎宫壬子癸等。
- <https://fengshui.tools/ja/free-luopan-calculator>：0°子／180°午，90°卯／270°酉；二十四山逐项中心及对向。

`backend/tests/test_fengshui_v70.py` 独立记录 24 组中心方位、坐向及八卦参考值，同时覆盖 7.5°、352.5°、337.5°跨界、九宫排序、360°归一、磁北 +5° 东偏/−6° 西偏、完整 API 拒错。

`backend/scripts/fengshui_v70_acceptance.py --output backend/acceptance-output/fengshui-v70.json` 生成可追溯验收证据；GitHub Actions 在全量回归及 Docker 镜像构建基础上再执行此独立锚点，不以程序自动计算结果作为预期。
