# V62 贵人昼夜起法与十二天将排布

采用十干贵人歌诀（昼、夜）：甲戊庚 **丑/未**、乙己 **子/申**、丙丁 **亥/酉**、壬癸 **巳/卯**、辛 **午/寅**。独立对照 [《六壬存验》](https://libokang.com/classics/liuren/六壬存验/) 具体贵人表。

固定传统时辰分昼夜：**卯、辰、巳、午、未、申**为昼，**酉、戌、亥、子、丑、寅**为夜。该规则独立于真实当地日出日落与经度。支持 `noble_mode=hour_branch|day|night`，默认为 hour_branch，可明确选择手动昼贵或夜贵比较古籍异文；不暗推太阳时或性别。

将所选贵人支在**天盘**上找到，反查其下临的地盘宫：地盘 **亥子丑寅卯辰**顺行，**巳午未申酉戌**逆行。在地盘按该方向排十二将，次序是 **贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后**。检查12地盘宫与12天盘支的天将皆成双射；将天将挂到十二宫、四课上神、已确认三传上神；未决课仍不生成三传。

### 两张独立验收例盘

- 来源：[Multifate · 十二天将完整盘示例](https://multifate.com/zh/guides/daliuren/twelve-generals)。戊日巳时昼占，若天地盘中丑临地盘寅，则寅贵人、卯螣蛇、辰朱雀、巳六合、午勾陈、未青龙、申天空、酉白虎、戌太常、亥玄武、子太阴、丑天后。本验收独立输入戊申日辰将巳时（丑临寅），逐地盘验证全部12将。
- 逆行：甲子日戌将子时，夜贵未落地盘酉，酉贵人、申螣蛇、未朱雀、戌天后等完整12宫均可校验。
- 所有十天干分别测试昼贵、夜贵；6个昼时/6个夜时边界；用户手动覆盖仍保留相同天地盘、四课、三传干支，但各宫天将不同。
- 历法接口请求参数默认为不传 `noble_mode` 以兼容 V61 客户端；同样验收8640张六壬基本盘，不猜测未决三传。

文献对十干两贵、昼夜边界确有不同。[《六壬指南》](https://libokang.com/classics/liuren/大六壬指南/) 和 [《袖里乾坤》争议讨论](https://www.zhaosir.online/Books/BookChapterDetail.aspx?did=921) 并非所有口径一致；本版命名并固定公开一套可复算口径，不声称各流派皆相同。
