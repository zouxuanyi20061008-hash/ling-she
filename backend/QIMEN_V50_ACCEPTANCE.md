# 万象书院 · V50 奇门遁甲基础起局

**范围**：时家奇门·甲己符头拆补定三元；北京时间；二十四节气查阳阴十八局；九宫地盘三奇六仪；按时柱旬首定位值符星、值使门的**本宫**。**不包含**天盘转九星、八门实际随时布宫、八神落位。

## 传统参考与固定验收例盘

底本：《[奇门遁甲元灵经](https://daizhige.org/易藏/术数/奇门遁甲元灵经.html)》卷一“奇门起例 / 阴阳各局 / 三元符头”。

- **芒种后癸亥日丙辰时**：原典明确“芒种下元，阳九局”，戊在离九、己在坎一、庚在坤二、辛在震三、壬在巽四、癸在中五、丁在乾六、丙在兑七、乙在艮八；时属甲寅旬，旬首癸在中五，值符本宫天禽、值使借坤二死门。V50 逐宫断言。
- **霜降后甲寅日辛未时**：阴遁八局，戊艮八、己兑七、庚乾六、辛中五、壬巽四、癸震三、丁坤二、丙坎一、乙离九；甲子旬首戊在艮八，值符本宫天任、值使生门。V50 逐宫断言。

计算基线采用 [lunar-python](https://github.com/6tail/lunar-python) 1.4.8 的交节与干支日期，将最近的节与最近的气比较取得**24节气**；六爻现有历法辅助只取 12 个“节”计算月建，不得直接挪用。时间限定1901–2099北京时间，可选子初或午夜换日。五鼠遁求时干支。节气交界15分钟、23时提示核查。

流派：定三元这里取最近甲或己符头的地支，按当下二十四节气表取局，属于当前选定的**即时拆补口径**；与置闰、茅山法、阴盘奇门不同。若发生具体流派争议，应补双方可复算例盘再扩充，不能暗换算法。

## 已实现

- 后端 `/api/qimen/cast`：输入公历日期、北京时间及换日规则，输出节气、日时干支、符头三元、阴阳遁局数、完整九宫地盘、旬首及本宫值符值使；非法输入422。
- 前端奇门入口显示可计算的地盘九宫；选宫显示本宫九星和八门**静态出处**，不把它们当作当值后的实际星门。
- CI 后端回归包含原典两例、全部24节气与上下中三元的72种局数状态、全部60干支×24小时五鼠遁、立春时刻、23点换日与API。

当前 V50 不是完整奇门实盘，不提供任何真实吉凶或择时结论。

CI 将保留独立的 `qimen-v50-earthplate-acceptance` JSON 附件，对《元灵经》两例的九宫干、局数及旬首本宫做逐条固定预期断言。另有奇门前端真实日期请求与拒绝非法日期的自动化交互测试。
