# V72 · 万象书院八门核心完整性审查

目标是 **检查八门是否真正可计算，并明确不可宣称已经完成的部分**，不扩建教学后台、美术或 AI 断语。

## 核心问题及本轮修复

| 审查项 | V71 原状 | V72 |
| --- | --- | --- |
| 八门有确定性 API | 已有 | 逐门真实 HTTP 起卦/排盘，并验证非虚构核心结构 |
| 未知参数 | 部分接口 Pydantic 默默丢弃 | 八门统一 `extra=forbid`，误拼字段或伪造时区返回 422 |
| 六爻六个铜钱爻值 | API 的 `int` 可能把 `7.0` / `"7"` 变成 7 | `StrictInt` 拒绝强制类型转换 |
| 太乙岁计年数 | API 可把 `2026.0` / `"2026"` 变成 2026 | `StrictInt` 并保留 1901–2099 年范围 |
| 八字流月/风水立极 | 仅传流月钟点/立极钟点可能被忽略 | 没有日期而单独传钟点明确返回 422 |
| 固定案例 | 分布在 V48–V71 不同测试 | 新增 V72 统一接口矩阵与独立验收 JSON |
| 排盘后更改参数 | 部分前端旧结果未失效 | V72 清除旧盘并防旧异步请求覆盖新输入 |

## 八门现状与待续工作

| 门派 | 已有实算 | 必须明确标注的缺口 |
| --- | --- | --- |
| 梅花易数 | 数字起卦，本互变、动爻、体用 | 非客观吉凶预测，具体象义需结合现实 |
| 六爻纳甲 | 三钱、纳甲、世应、六亲六神、旬空、日月、动变与多证据链 | 最终用神、旺衰生效、应期不可自动断定 |
| 奇门遁甲 | 节气拆补、十八局九宫、天地盘、星门神、三奇格局 | 流派完整盘式和最终断课仍待校勘，`has_complete_rotating_plate=false` |
| 四柱八字 | 立春四柱、十神藏干、大运及流月 | 真太阳时、人工取用、完整命理判断 |
| 大六壬 | 月将天地盘、四课、条件可判的三传、旬空遁干 | 有些九宗门分支继续保持 pending |
| 太乙神数 | 古籍岁计积年、五元六纪、七十二局、主客定计 | 时计、不同尺度及特殊流派细法 |
| 紫微斗数 | 命身宫十四主星、十二辅曜、生年四化及异文选项 | 其他杂曜、流年流运四化、小限 |
| 堪舆风水 | 二十四山、坐向、立春三元九运、玄空下卦三盘 | 替卦分金、流年飞星、真实罗盘及形势 |

**验收限制：**八门全部能得到真实计算输出 ≠ 八门各派完整算法都已实现；本轮不为教学、吉凶、个人命运或现实事件制造不存在的结论。

使用 `PYTHONPATH=backend python backend/scripts/eight_arts_v72_audit.py --output backend/acceptance-output/eight-arts-v72.json` 可输出 8 门逐项契约、独立真值和未完成范围；另在 `backend/tests/test_eight_arts_v72.py` 中保留多维拒错测试，CI 正式运行脚本并上传 JSON 证据。
