# 万象书院 · 六爻 V48 核心功能验收基线

**范围**：六爻（三钱六掷）从输入 → 本变卦 → 八宫纳甲世应 → 日月六神旬空 → 飞伏与用神候选 → 明动来源 → 空破等条件审议 → 五步报告。

**验收日期**：2026-10-27。这里的“通过”专指自动化规则一致性，不等于所有传统流派完整正确，更不代表预测有效。

## 可重复的自动化验收

每次推送 `meihua-web-deploy`，GitHub Actions 除运行原有后端与前端回归测试外，还执行：

```bash
PYTHONPATH=backend python backend/scripts/liuyao_v48_acceptance.py --output backend/acceptance-output/liuyao-v48.json
```

CI 的 `liuyao-v48-acceptance` Artifact 保留机器可读 JSON：被测提交、64 卦 × 7 种动爻数量（0～6）的 448 盘、乾卦全部 64 种动爻掩码、固定历史卦例、通过状态及未实现项。任何断言失败会终止部署流程。

该跨模块验收还逐盘对照下卦/上卦、本变六爻、自下而上爻位、八宫世应、内外纳甲、六亲、甲子旬空戌亥、辰月冲戌、本位真实动变、五爻之外的明动作用边、两两动爻组数、跨模块去重、五步报告和不得自动生成吉凶/应期。

## 固定锚点（不依赖随机数）

- 乾为天父母三、上爻两现；用户指定上爻仍必须保留所有候选；甲子戌亥空、辰戌冲并见。
- 六老阴坤为地变乾为天；本卦六老阳全动时两两共 15 组，且须识别原神/忌神真动与仇神双段候选。
- 天风姤妻财不现：二爻甲寅伏于辛亥之下，不得将伏神误当明现用神。
- 2026 年立春前后月建丑→寅；同一天不同交节时刻不应自行换日。23:30 的午夜与子时换日约定须区分。
- 缺失日月时不应凭空断出旬空、月破或具体应期。

## 剩余缺口和建议的开发顺序

1. **六爻的真实算法缺口**：明确《增删卜易》等典籍的可执行规则范围和分歧，建立独立的“输入 → 古籍例盘 → 预期结果”真值集；优先补最终用神取舍前的效力裁决规则。不要用 V44–V47 的标记条数冒充断卦算法。
2. **六爻实际交互验收**：按 5 步完整操作真实网站，验证日期采纳、用神选位、前后端结果、刷新和导出。GitHub CI 的构建测试不能证明 Render Live 已切到最新版本。
3. **其余术数门类**：先审查各门已经完成的排盘内核和调用路径，把尚未实现的主要功能列为下一阶段优先项；教程、藏经阁和美术继续后置。

当新增六爻规则时，必须在验收矩阵和固定古籍卦例同时增加测试；不能只修改文案或加新的提示面板。
