# V76 · 六壬反吟复等古籍证据范围锁定

目标：**提高核心排盘的正确性与依据透明度，而非人为将未决盘归零**。

## 原典对照与 V75 真实缺陷

《大六壬探原·推演篇》在规则段明载，**戊辰、戊戌两日反吟类缀瑕复等**，干上取亥，三传「亥巳亥」，这是覆盖两日的**明示规则**。

《六壬存验·返吟课占功名》独立收录的是 **戊辰日、春分后戌将、丙辰时**一张实占，四课为：
**亥戊、巳亥、戌辰、辰戌**，初巳、中亥、末巳。它是一张**特定课**，不能因为反吟盘同形，就从一个时将组合扩大至另 11 个。V75 将“戊辰日”单独视为足够条件，过度扩展了《存验》原证据。

原始公开资料：
- [《大六壬探原》原文](https://shuyuan.zhiming.life/read/大六壬探原(推演篇)-上/1)：说明反吟两日复等干上亥的通则。
- [《六壬存验》原文](https://libokang.com/classics/liuren/六壬存验/)：戊辰戌将丙辰时的实际整课及三传。

## V76 严格条件

- 默认 `fanyin_tie_school="pending"`：8640 盘中已计算 **8616**，仍有 **24** 待判（戊辰、戊戌日各 12 个互冲时将组合）。
- 手动 `"tanyuan"`：取经典**明载两日规则**，对其 24 个同形盘可得到亥巳亥，附规则出处。
- 手动 `"cunyan"`：仅戊辰日、**戌将、辰时**且四课完全符合**亥戊、巳亥、戌辰、辰戌**方可给巳亥巳。其他 23 个未决组合**不猜**，仍为 `pending`；若曾选了该来源，显示不适用原因。
- 新加 `historical_witness_v76`：明示原例范围、精确四课、证据性质（文本规则 vs 单例）、当前取法与三传状态。前端能够核对原文链接。
- 老牌 `version=V63`、`audit_version=V74`、V75 结构和已有 API 输入字段继续保持兼容；新增 `witness_version=V76` 仅供有反吟涉害审查的盘核验。

## 回归验收

`backend/tests/test_liuren_v76.py` 含原文四课真值、同形不等于同一实占、24 盘两日三套取法、API 兼容、错误证据注入。独立脚本 `backend/scripts/liuren_v76_acceptance.py` 从**全量 8640 盘**产出证据文件，CI 上传 JSON，并由 Docker 内全量测试复核。

**未完成范围：**不同原典中的复等选法仍存在冲突，不能将某一张预测应验故事当作算法普遍正确性的证明，亦不能据此生成吉凶判断或应期。
