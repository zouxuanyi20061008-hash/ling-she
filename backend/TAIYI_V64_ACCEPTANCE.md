# 万象书院 V64 太乙神数 · 岁计年局、积年、五元、八宫

**口径：只做古籍可独立复核的岁计阳遁**。太乙术有岁、月、日、时四计；古籍《[太乙金钥匙](https://www.shidianguji.com/book/NGJ89241199902106666022/chapter/1lq8dkylq3yn8)》明确“惟时计有二至之别”，而当代网络说明不总一致，V64 不把冬至阳遁夏至阴遁直接套给任意一年。公历年界使用原史书标注的名义年度，未另称立春或冬至为岁计换年边界。

年积年选取《[钦定古今图书集成·艺术典第688卷](https://zh.wikisource.org/wiki/欽定古今圖書集成/博物彙編/藝術典/第688卷)》的 **1624 甲子年 = 10,155,541 积年**；另一书《太乙金钥匙》 **1561 辛酉年 = 10,155,478 积年**，相隔恰好63年。注：另一传承有“唐开元十二年724年=1,937,281积年”，不能把不同传系拼接。历史锚点更利于用户复算：`acc = 10155541 + (year - 1624)`。

历史定位：
- 1561 年：`10155478 %360 =238`，第四庚子元22局，九宫巽，理天；《太乙金钥匙》并载文昌阴德、主算16、始击天道、客算30。
- 1624 年：`10155541 %360 =301`，第五壬子元13局，六宫兑，理天；《古今图书集成》并载文昌大炅、主算18、始击太阳、客算19。
- 2026 年按同一系：积年10,155,943，360周余343，即第五壬子元55局，三宫艮，理天。**主客数据不随意填出。**

余数0视为上一周期末尾：`((acc-1) %360)+1` 求360周余。再除72定位五元，72局每3年一宫、24年回八宫，依太乙式专用一乾、二离、三艮、四震、六兑、七坤、八坎、九巽 **不入中五**；六十纪用于日干支年与计神寅起逆行。普通洛书1坎等并非此处的太乙式数，前端独立九宫展示不挪用奇门盘。

**主客**：《太乙金镜式经》需要文昌天目、始击地目、十六神重复留算和主客投算；V64 仅保存古籍1561/1624两组已知原文数值作**原文锚点**，并明确标注 `main_guest.status=pending`、`main_calculated=null`、`guest_calculated=null`。下一版V65验证文昌与始击之后再提供真实任意年度的主客数，不把文献固定数值硬插未来年份。

后端独立测试含：二历史例盘、2024/2026实算、72局全环、二十四年/七十二年/三百六十年周期、1901至2099全公共年份、非法输入422及中宫永不入。原先其他六门测试照旧，本站仍支持中国北京时间历法功能。没有吉凶断课或现代事件预测。
