# V85 · 《太乙金镜式经》独立阴遁时计例与六纪天目相位

本轮继续核心计算，不新增教程/后台。古籍来源：[《太乙金镜式经》卷一](https://zh.wikisource.org/zh-hans/太乙金鏡式經_(四庫全書本)/卷01)，包含“推求阳遁太乙直使法”“求阴遁太乙直使之法”与“推太乙当时法”的时计专例。

## 独立古籍真值：阴遁第六纪壬子元二十七局

唐王希明举一张立冬阴遁时计：**第六纪、壬子元、27 局、太乙九宫、天目大武、计神午**；**主算 29、主大将九、主参将七；始击高丛、客算 4、客大将四、客参将二**。

正确积数须同时满足：
- 六纪每纪60时；第六纪表示 `301..360`，五元第五元 `289..360`，局内第27局，故周内第 **315 时**。只输入 `27` 会落甲子元第一纪，不能冒充此例。**特别注意：315−27=288，恰能被24、18和12整除，因此两数的太乙、文昌、计神及局部主客算恰巧相同！必须核对五元与六纪，不可仅凭局部盘一致证明积时元纪正确。**
- 使用 `classical_hour_ju(315,"阴遁")` 和 `calculate_hour_main_guest` 真正计算全部指标及两方逐宫投算，并与**预先独立录入的**古籍真值按字段逐一比较。
- 这是一张**史料写明局元纪的历史时计例盘**，不是直接证明2026年某个二至瞬间纪首恰有同一相位，更不是现代实际事件吉凶判断。

## 六纪天目起点、未知历元和三相条件模型

《金镜式经》记张良六纪旧法的起点：
- **阳遁**：武德 → 地主 → 大炅，重复于纪4/5/6。
- **阴遁**：吕申 → 大威 → 阴德，重复于纪4/5/6。
- 每纪60时，文昌十八算周循环；`hour_wenchang_from_count(1+60*i,dun)` 的三个纪首与史料一一对应。将 `relative_hours` 分别加 `0/60/120`，得到三种历史**纪首相位假设**下的文昌、始击、主算、客算、大参将；对与太乙同宫者保留 pending。
- 然而王希明明确反驳**人为指定每次冬夏至一定在甲子纪首**的旧法。真实二至气应时的纪首相位/古代上元绝对历元尚未校准；这三种只覆盖史文六纪的起始相位，**不是任意未知时差的完整枚举**。默认 `preferred_phase=null`；并且 `confirmed_qiying_wenchang/shiji/main_general/guest_general=null`。
- 已验 V84 的气应派太乙、计神、直使与独立甲子派原盘均不被更改。不能从某一历史例盘或任意假设中偷选今日主客将。
