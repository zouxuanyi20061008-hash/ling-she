# V79 · 太乙时计始击、主客算与四将（甲子日简捷积时法）

## 范围及真实算式

建立在 V78 **二至前甲子日简捷积时** 的太乙时局上，与 V77 交节后相对时实和 V67 岁计独立。

- 先取 V78 `time_wenchang` 十六神索引、`time_jishen` 和太乙宫。**始击**以 `计神加艮和德`：`(文昌索引+艮索引−计神索引) mod 16`，不可反向。
- **主客算**分别从文昌、始击所在十六神位顺行到太乙宫前截止：起于间位按一算，过正宫计宫数，中途间位不加数，太乙本宫不计。
- 主算和客算各自去十用零（十/二十取一/二）；大将再三因得参将。若目与太乙同宫，按 V65 保守待判并给原典参考，不自动套用 V66 **岁计**同宫法。
- `hour_main_guest_v79` 含文昌、始击与计神所在十六神位置、逐位投算路径、大小将、保留未决的原因、双历元来源标签；旧 API `version=V77`、`historical_ju_version=V78` 不变。
- 对结果具备 `status=computed/partially_computed/pending` 明确标记；`has_full_hour_chart` 永远保持 false，定计目、合神、八门与真实占断后续校勘。

## 独立原典唯一完整真值

[《太乙金钥匙·续集》“庚戌时计式”](https://www.shidianguji.com/book/NGJ89241199902106666022/chapter/1lq8dkylq3yn8) 载：`(74-1)*12+11=887`，戊子元阳遁23局，太乙巽九宫第二时，文昌阴德、计神辰、始击武德：

- 主算路径：阴德作为间位 1 + 地主8 + 和德3 + 高丛4 = **16**。
- 客算路径：武德作为间位 1 + 太簇6 + 阴德1 + 地主8 + 和德3 + 高丛4 = **23**。
- 主大将 **6**、主参将 **8**；客大将 **3**、客参将 **9**。
- 原典中如「嘉靖四十年辛酉庚戌时」是一个**古代时刻固定案例**，不把同数 887 的某个现代日期冒充该历史占例。
- 辅助算法依据：[《太乙金镜式经·推太乙运式法》](https://www.shidianguji.com/book/SK1615/chapter/1l9lir7w2mwii)；[《太乙金钥匙·一卷》](https://www.shidianguji.com/book/NGJ89241199902106666022/chapter/1lq8dkvlnkx7u)。
